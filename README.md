# SYCLE V2

**Kenali Lingkunganmu, Proteksi Awalmu.** — Final project Perempuan Inovasi 2026.

PWA desktop-first berbahasa Indonesia: Next.js 16 (App Router), JavaScript/JSX, Tailwind CSS,
shadcn/ui, Supabase (tahap berikutnya), Vercel.

Aturan proyek: `../CLAUDE.md`. Audit & rencana: `../docs/AUDIT_SYCLE_V2.md`.
Progres: `../docs/PROGRES_PENGEMBANGAN.md`.

## Menjalankan

```bash
npm install
cp .env.example .env.local
npm run dev     # http://localhost:3000
npm test        # Jest
npm run lint
npm run build
```

Halaman pratinjau komponen (khusus development): `/pratinjau-komponen`.
